# Ads Agent deliberately not built yet

## What was decided

An **Ads Agent** — a fifth agent alongside [[Zapier Overseer Agent]],
[[Scheduler Agent]], [[Bookkeeper Agent]], and [[Site Editor Agent]] — is
not being built right now, on purpose.

## Why

Spotless Cleaning doesn't currently run any paid ads — marketing right now
is organic Facebook posts in local Lake Havasu City groups. Bryce wants to
eventually run paid ads on Google Ads and Meta (covers both Facebook and
Instagram placements), but building an Ads Agent and its performance graphs
now, before any real campaigns exist, would mean building graphs with
nothing real to show. The build is deferred until real ad campaigns exist
to pull data from.

## What this touches

See [[systems-overview]] → "What's not built yet." When paid ad campaigns
actually start, this is the natural trigger to revisit building the Ads
Agent — not before.
